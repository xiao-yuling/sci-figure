# QA checklist

Before delivery, verify:

- The figure has a clear core conclusion.
- Every panel contributes distinct evidence.
- The selected backend is used consistently.
- SVG/PDF text remains editable.
- Font sizes match the final output size.
- Axis labels include units where needed.
- Ticks appear only on the left and bottom and point outward.
- Four spines are visible unless the target template requires open axes.
- Single plots do not use panel letters.
- Multi-panel figures use consistent integrated panel titles.
- Legends are necessary, concise, and frameless.
- Colors remain readable in grayscale.
- Statistical annotations define the statistic and sample size when manuscript-facing.
- Source data and transformations are traceable.
- Generated preview files match the exported vector/raster files.
